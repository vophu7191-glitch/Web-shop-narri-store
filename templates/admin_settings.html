Cách dùng: gửi header X-API-Key: <key> (hoặc query ?api_key=<key>) tới các endpoint:

  • GET {{ api_base }}/ping — test kết nối
  • GET {{ api_base }}/stats — thống kê doanh thu / user / kho
  • GET {{ api_base }}/users?q=&limit=50 — danh sách user
  • GET {{ api_base }}/users/<id-hoặc-username> — chi tiết user
  • GET {{ api_base }}/orders?status=pending&user_id=&limit=50 — danh sách đơn
  • GET {{ api_base }}/orders/<order_id> — chi tiết đơn
  • GET {{ api_base }}/products?brand=redfinger — danh sách sản phẩm + tồn kho
  • GET {{ api_base }}/recharges?user_id=&limit=50 — lịch sử nạp tiền

Ví dụ (Python):
requests.get("{{ api_base }}/stats", headers={"X-API-Key": "<key>"}).json()
